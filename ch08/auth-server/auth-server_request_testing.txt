=========. The command to request the token

The book version:

curl -v -X POST 'http://localhost:9000/oauth2/token' \
-H "Content-Type: application/x-www-form-urlencoded" \
-d "grant_type=authorization_code" \
-d "redirect_uri=http://127.0.0.1:9090/login/oauth2/code/taco-admin-client" \
-d "code=NcqgFL5aCHUls6iPwSMCG2V8lJxv8gwLILkdEHUzoBMpF2SNXXGqS98FTbBzHS4IVCl-2IIpOrjCsv3q6mF5ifwxqQONo6WszElOcUeJQLP6m1sQp5EW3H4pcvxUvYfF" \
-u "taco-admin-client:secret"
